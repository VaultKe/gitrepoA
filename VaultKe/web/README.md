# VaultKe APK Distribution — Web Frontend

Static React frontend for the VaultKe Play Console, designed for GitHub Pages deployment.

## Deploy to GitHub Pages

```bash
npm install
npm run build
npm run deploy
```

## Configuration

Set `VITE_API_BASE_URL` environment variable to point to your VaultKe API backend:

```
VITE_API_BASE_URL=https://your-api.example.com/api/v1
```

## Development

```bash
npm install
npm run dev
```
